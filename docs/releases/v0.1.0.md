# SkezMod v0.1.0 - Stars Patch

## Release

- Name: `Stars Patch`
- Channel: `stable`
- Target: `MANAGPRE.EXE` (x86 PE, image base `0x00400000`)

## What this patch changes

- Null guard at `0x0066F1FB`:
  - protects the `0x0066F208` dereference path in `FUN_0066F1F0`
  - NULL text pointer is normalized to empty text path
- Lookup fallback at `0x004B5C76` in `FUN_004B5C20`:
  - unresolved/invalid candidate records no longer return NULL
  - fallback records:
    - team id `0` -> `Unknown club`
    - team id `4705` -> `Stars`
    - team id `4706` -> `Free players`
- RC1 wrapper hooks are not part of this release:
  - `0x004B8C3D`
  - `0x004B8C73`
  - `0x004B8F09`
  - `0x004B8F3F`

## CLI

```bash
python stars_patch.py --input /path/to/MANAGPRE.EXE --output /tmp/MANAGPRE.stars_patch.EXE
```

Supported flags:

- `--in-place`
- `--dry-run`
- `--force`
- `--no-backup`
- `--json-output /tmp/stars_patch_report.json`

## Idempotence and rollback

- Re-running the patch on an already patched file is supported.
- In-place mode writes a timestamped backup by default.
- Rollback is done by restoring that backup file.
