# SkezMod v0.1.0

## Release

- Name: `SkezMod`
- Channel: `stable`
- Target: `MANAGPRE.EXE` (x86 PE, image base `0x00400000`)

## What this patch changes

- Null guard at `0x0066F1FB`:
  - protects the `0x0066F208` dereference path in `FUN_0066F1F0`
  - NULL text pointer is normalized to empty text path
- Lookup fallback at `0x004B5C76` in `FUN_004B5C20`:
  - unresolved/invalid candidate records no longer return NULL
  - fallback records:
    - team id `0` -> `Unknown club`
    - team id `4705` -> `Stars`
    - team id `4706` -> `Free players`
- Formatter-local fallback at `0x00499DA1` in `FUN_00499D00`:
  - when a notice template supplies null `{S3}`, the formatter resolves the event team id through `FUN_004B5C20`
  - this uses the shared fallback records, so all covered Stars/free-player records get the correct suffix without player-specific checks
- Search hover/status fallback at `0x00406116` in `FUN_00405F30`:
  - blank special-club text (`0x26AC`) is replaced with the fallback team name for the hovered player
- RC1 wrapper hooks are not part of this release:
  - `0x004B8C3D`
  - `0x004B8C73`
  - `0x004B8F09`
  - `0x004B8F3F`

## CLI

```bash
python skezmod.py --input /path/to/MANAGPRE.EXE --output /tmp/MANAGPRE.skezmod.exe
```

Supported flags:

- `--dry-run`
- `--force`
- `--json-output /tmp/skezmod_report.json`

## Idempotence and rollback

- Re-running the patch on an already patched file is supported.
- When run with defaults in the PM99 folder, the tool auto-rotates:
  - `MANAGPRE.EXE` -> `MANAGPRE.original.exe`
  - `MANAGPRE.skezmod.exe` -> `MANAGPRE.EXE`
- Rollback is done by restoring `MANAGPRE.original.exe`.
